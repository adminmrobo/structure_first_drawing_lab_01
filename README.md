# 구조 먼저 그리기 연구실 01 · 옷장 편

> 같은 원리, 다른 옷 — 사진 속 옷을 그림으로 옮기는 순서, 핏·체형·소재·동작에 따라 달라지는 주름을 실험으로 익히고, AI 프롬프트·가림 영역·VFX 천 시뮬레이션으로 옷을 갈아입혀 봅니다.

**사이트:** https://adminmrobo.github.io/structure_first_drawing_lab_01/
**앞 시리즈:** [구조 먼저 보는 캐릭터 그리기 연구실](https://adminmrobo.github.io/adminmrobo-structure_first_drawing_lab/) (구조·빛·주름 기초)

## 등장인물
| 역할 | 캐릭터 |
|---|---|
| 모델 | 인턴2 모아(1·3부), 조수 하루(2부), 인턴1 시아(4부), 5부는 셋 모두 |
| 손님 모델 | 박사(3·5부, 셔츠·조끼·넥타이) |
| 화가 | 주판봇(성급하게 결과부터), 초파리 연구원(원리부터 의심) |
| 평가단 | X1·X2·X3 |
| 해설 | 박사 |

모델은 모두 20대 성인 연구원입니다. 원리 실습은 연구실 의상(랩코트·티셔츠·카디건·울 코트·메이드복·셔츠와 조끼)으로 합니다.

## 구성
| 부 | 페이지 | 다루는 것 |
|---|---|---|
| 목차 | `index.html` | 읽는 순서, 큰 그림, 등장인물, 원리와 출처 |
| 1부 | `01_photo_to_drawing.html` | 큰 주름부터(세기 비율), 그림체별 정보량, 그림자 다섯 단계, 경계 흐림(반지름 × 각도) |
| 2부 | `02_fit.html` | 여유율, 자세별 접점, 몸의 볼륨과 밑단(피타고라스), 선 대신 그림자 |
| 3부 | `03_material.html` | 두께와 주름 간격(두께^(3/4)), 마름모 그림자, 버릇 주름(1 − (1 − p)ⁿ), 겹쳐 입기 |
| 4부 | `04_motion.html` | 걸을 때 공기(속도²), 주름치마의 보이는 뒷면(cos), 굽힘의 길이 차이, 소품 접점 |
| 5부 | `05_ai_vfx.html` | 옷 고정 문장, 가림 영역(인페인팅), VFX 소재표(천 시뮬레이션), 화풍별 주름의 양 |
| 6부 | `06_failure_lab.html` | 옷 그림 실패 8종 진단 + 옷 이름이 나이를 바꾸는 현상 |
| 7부 | `practice/index.html` | 실전 연습장: 피팅룸·소재 실험실·옷 문장 공방·진단 데스크 |

모든 실험은 외부 라이브러리 없이 동작하며, 그림 파일이 없어도 페이지가 완성 상태입니다.

## 그림
- 그림 34장(표지 8 + 본문 26)은 Genspark로 만듭니다. 요청문: `docs/image_requests/` (저장 이름은 `checklist.csv`).
- 받은 그림은 `assets/img/{이름}.webp`로 넣고 `python3 build/build.py`를 다시 돌리면 '그림 준비 중' 자리가 채워집니다. 표지가 들어오면 `python3 build/make_og.py`로 공유 미리보기를 다시 만듭니다.
- 표지는 16비트 픽셀아트, 본문은 애니풍·반실사·실사풍을 허용합니다(이 시리즈 예외). 실사풍은 캐릭터를 코스프레한 가상의 성인 모델이며 실존 인물이 아닙니다.

## 빌드와 점검
```
python3 build/build.py          # 페이지 만들기 (assets/panels.js는 build/js_*.js를 이어 붙여 만든다)
python3 build/check_numbers.py  # 본문 숫자 검산
python3 build/make_og.py        # 공유 미리보기 그림
python3 build/check_pages.py    # 화면 넘침·콘솔 오류 점검 (로컬 서버 8765번 필요)
python3 build/check_missions.py # 실전 연습장 미션 판정 점검 (로컬 서버 8765번 필요)
```

## 원리와 출처
1~4부의 그리기 원리는 일반적인 드로잉 원리이며, 다테 나오토 『デジタルツールで描く！服のシワと影の描き方』(マイナビ) 2장 실례편을 참고해 정리했습니다. 책의 사진·그림·문장·도식은 옮기지 않고 연구실 캐릭터와 실험으로 새로 구성했으며, 책의 학교 교복 예시는 연구실 의상으로 바꿔 다뤘습니다. 주름 간격 식은 Cerda·Mahadevan(2003), 천 시뮬레이션은 Baraff·Witkin(1998)과 Jakobsen(2001), 가림 영역 다시 그리기는 RePaint(2022)·잠재 확산 모델(2022)을 바탕으로 쉽게 풀었습니다. 전체 목록은 각 페이지 바닥글에 있습니다.
