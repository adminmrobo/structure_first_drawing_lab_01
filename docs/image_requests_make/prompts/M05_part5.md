# M05 · 5부 '직접 만들어 보기' 비교 그림

**Genspark에 먼저 붙여 넣기 ↓**
```
해설 페이지의 '직접 만들어 보기' 비교 그림을 만들어 줘.
- 첨부한 그림(이미 만든 A 결과)과 똑같은 캐릭터·구도·화풍·빛을 유지하고, 아래 'Change only'에 적힌 것만 바꿀 것
- 비율은 첨부한 A 결과와 같게
- 등장인물은 모두 20대 성인(박사는 성인 남성). 노출·교복 느낌 금지
- 그림 안에 글자·숫자·로고 금지
```

## p5_haru_inpaint_real — 옷만 다시 그리기 — 부분 수정 기능으로
첨부: refs/haru_anime_base.png (Genspark 이미지 편집·부분 수정 기능에서)
방법: 그림 생성이 아니라 '부분 수정(영역 칠하기)' 기능으로
```
1) 하루 그림(예: 앞 시리즈의 애니풍 기준 전신)을 올립니다.
2) 수정 붓으로 몸통과 팔만 칠합니다. 얼굴·머리 번·남색 줄은 피하고, 옷보다 조금 넉넉하게.
3) 프롬프트: camel knit cardigan over a white blouse, red and navy plaid bow tie, soft thick knit with broad rounded folds, light from the upper left. Keep the face and hair unchanged.
4) 결과가 이음매를 보이면 칠한 영역을 조금 넓히거나 경계를 흐리게 해 다시.
```
